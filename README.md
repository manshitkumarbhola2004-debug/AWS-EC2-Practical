# AWS EC2 Practical

## Introduction
This project demonstrates how to launch
and configure an Amazon EC2 instance.

## Objective
To understand AWS EC2 and learn how
to create and connect to a cloud server.

## Services Used
- Amazon EC2
- Amazon Linux 2023
- Security Groups
- Key Pair

## Tasks Performed
1. Created EC2 instance.
2. Configured security settings.
3. Connected to EC2 instance.
4. Executed Linux commands.

## Learning Outcomes
- Understanding cloud computing.
- Creating virtual machines.
- Connecting to Linux servers.
- Basic server management.
